# Optional Fast Dist supplied-host factory

This separately compiled no-editor factory reconstructs five controls, coefficient arithmetic and state. It delegates sample processing to the borrowed C++ host's measured DistWave ordinal 24. The runtime does not reconstruct that host or its DSP, infer quality from mode flags, read native globals, or use the independent table DSP. Existing default-quality0 and editor implementations remain separate.

The borrowed host/interface/VMT and synchronous, nonthrowing, nonreentrant callback must remain live through every call and plugin destruction. All instance and host access is serialized or protected by the caller's host mix lock. See host_delegated_native.h and the unchanged fast_dist_plugin.h for control and FP contracts. Audio is finite stereo with abs(input)<=16 and 0..1024 frames; exact alias or disjoint external buffers are supported. The source validates before copying input and forwarding type, threshold, output, 2*frames, dry, wet, multiplier. Partial or instance aliases and unsupported audio reject atomically; these guards extend the new API and do not establish malformed-original equivalence. Names need 10 writable bytes. Tested FP is nearest-even, gradual and nontrapping with the recipe's disclosed flags.

The actual CPPHost constructor produces a 24-byte facade with Pascal parent at +8 and C++ interface at +16. DistWave ordinal 24 follows thunk 0xb4e8c0 and forwarder 0xb4cf80 into Pascal VMT+0x188. The fixture constructs real host/plugin adapters and also executes intact DLL loader 0x3e1450. A controlled 512-byte parent stays live until both source instances, wrappers and facades are destroyed. The fixture temporarily supplies that parent through engine global 0x18d9758 and prepares selector 0/1 at 0x19b4a28, then restores/readbacks the saved 8-byte global and selector byte after nominal destruction. It does not run the application's host constructor or selector writer. Native table initialization, unlisted globals/TLS/VCL/module caches and failure-process cleanup are excluded from whole-state restoration claims.

Normal and fatal ASan/UBSan/float-cast-overflow checks produce identical results: 18,000 original/source control calls, 2,400 source saves, 720 target restores, 7,200 render callbacks/844,200 stereo frames/1,688,400 exact sample bits. Of those callbacks, 4,800 traverse actual CPPHost ordinal 24 and 2,400 original callbacks use Pascal DistWave directly. Both prepared selectors run every block. An independent numerical API used only by the fixture matches both; opposite quality differs 45,748 sample bits. Capture checks receiver, controls, scalar sample count, three coefficient values and input samples before DSP. Signed zero, input immutability, output guards, exact alias/disjoint buffers and prepared-parent/global guards pass. Both source adapters exercise 20 reviewed callback slots each. The two extra C++ destructor entries/general ownership are not separately replayed.

The source-only audio guards reject 431 calls without host calls or instance mutation, including 416 zero-frame interior-instance buffer aliases. Four synthetic failed-status/short-count restores preserve state. Intact TMemoryStream/TStreamAdapter checks 128 saves/restores of one 20-byte packet, signed 32-bit HRESULT, 32-bit completion count with adjacent high-word sentinel, actual invalid-pointer error, and full-count failed HRESULT/short-success atomic rejection preserving coefficients. General failed writes/provider behavior remains unproved.

The maintained wrong-count mutant forwards frames rather than 2*frames through the same actual host ordinal. Its unchanged target order is original, manual real C++ host/plugin adapter, then loaded adapter. It first fails at the manual adapter in case 1, selector 0, one stereo frame; the loaded instance was constructed but its render is not reached in that failing iteration. A separate independent reviewer-only loader-first mutant also fails through the intact loaded adapter. These are distinct proofs; the maintained negative does not itself establish the second route. No incompatible original ordinal is invoked.
