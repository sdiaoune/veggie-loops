# Balance public protocol corrections

This independently written candidate fixes three observed protocol issues. For valid control indices0/1, name section0 returns the measured installed English captions `^b^aBalance` and `^b^aVolume`; measured sections1..9 preserve the caller buffer. Event1 stores its full signed int32 value in a separate private maximum-polyphony field initialized to the observed zero value. It never writes the public MonoRender field. Native calls and private test snapshots must be serialized; GUI locks do not provide general synchronization. Unsupported sections/indices and null output are defensive source behavior, with no invalid-original comparison or localization certificate.

The C++ complete destructor releases owned numerical/editor resources and ends the Instance lifetime without deallocating its storage. The caller may then perform matching raw-storage deallocation only; no getter or second destructor callback is valid after success. DestroyObject and the deleting destructor additionally deallocate exactly once. All three optional editor entries require the main thread. An off-main refusal preserves the entire object; the caller retains the host/module/storage and retries on the main thread, without freeing after refusal. This source lifetime correction follows separately compiled SDK semantics; no uncertain original extra-destructor route is invoked or certified.

The own diagnostic module includes exactly this implementation and adds a private getter solely for the fixture; production modules do not export that getter. Original images are uninstrumented.
