# Own Soft Clipper and Stereo Shaper lifetimes

These experimental factories now distinguish complete cleanup from deleting
cleanup. Complete callback20 ends the instance and retains raw storage for the
matching caller release. Callbacks0/21 end and free it. All destruction in builds
with optional editors requires the main thread, including before attachment;
refused worker cleanup retains ownership for retry.
Successful cleanup clears retained view callbacks/context and all control targets.
The host, module and view lifetime requirements remain part of the own API.

Two independent source runtime reviews accepted12 normal/fatal/O0 profiles and14
fatal semantic negatives. Two separate engine runtime critics accepted18 exact
normal/fatal result documents and26 signed arm64 products per replay. These checks
cover the intact engine's ordinary loader, streams, routing and optional AppKit
editor adapters with controlled hosts/providers. A new installed-effect DSP
comparison and original extra-destructor calls are outside this repair.

python3 reconstruction/plugins/effects/soft-stereo-lifetime/verify.py

Run sequentially on macOS arm64 with Xcode command-line tools and the pinned
FL Studio installation. `--phase source` loads only own code and system frameworks;
`--phase native` runs the controlled engine checks. `--check-only` checks published
source bindings without compiling or reading originals. The wrapper creates a
fresh ignored copy and signs/strictly verifies own products before use. Optimized
Python is refused. The source fixture instruments own allocation counters;
installed code is unmodified and uninstrumented. The two recipes retain their
accepted bodies; the source recipe adds early optimization/copied-workspace guards.
After creating its work tree, the wrapper records source, copied-input, manifest
and applicable original-identity checks in a final audit on success and failure.

Stereo Shaper cleanup preserves its existing borrowed-host policy: it does not
invent a send-unregister event. Actual application registration cleanup ownership
remains unknown. Preserved critic fixture/helper failures identify their failing
checks and are excluded from accepted results. The first source supplement required
matching Soft Clipper's actual detach-meter toggle in its reference fixture.

Only matching raw deallocation is allowed after successful complete destruction;
the ended instance cannot be used or destroyed again. Original class/GUI/extra
destructors/general allocator, natural application/project/mixer hosting, broader
provider failures, concurrency/real-time, x86/VST/AU and whole-plugin equivalence
remain unproved. Public package replay status is recorded in `verification.json`.
