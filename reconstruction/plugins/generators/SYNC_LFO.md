# Synchronized 3x Osc LFO metadata

This original module supplies a serial C API for the five envelope/LFO groups' synchronized phase registry. It reconstructs group registration, explicit tick and song-position updates, the internal dirty latch, pending-tick retention and the release-refresh hint. It has no audio renderer, native factory, allocating list or concurrent atomic ABI.

`./reconstruction/plugins/generators/verify-sync-lfo.sh` builds and loads a separate helper dylib, then compares its metadata against the installed original's actual factory and public parameter, `NewTick`, `SongPosChanged` and `GenRender` methods. The fixture checks the wrapper and two dependency hashes before loading them and refuses any executable architecture other than macOS arm64. Independently generated legacy tables and reconstructed coefficient preparation supply the fixture's inputs; commercial code, assets and tables are not embedded in the rebuilt helper.

The configuration's internal dirty word is at `+0x334`. Public parameter 113 is the filter mode at `+0x330`, saved at payload `+452`. They are distinct. The group-control setter at arm64 offset `95660` marks the dirty word using exchange helper `4d20`. On a nonempty frame, `1bc3d0` clears context `+0x24`, consumes dirty `1→0` through compare-exchange `4d60` and, when consumed, rebuilds the synchronized registry through `1bc310`. Registration tests group flag 32. The rebuild searches each group in current order, removes it by replacing its slot with the last registered group, then appends it if flag 32 is set. The native list's policy byte at `+0x18` is 0, selecting this unordered removal in `149e30`. Phase values survive registration changes. When the volume envelope is disabled, consuming dirty sets the release-refresh hint. The helper records the hint; it does not apply the native voice rerelease/audio transitions.

Public `NewTick` at `5e910` reaches `1bc770`/`1bc690`, sets context `+0x20` pending and adds each registered group's prepared increment to its synchronized phase modulo 2^32. `SongPosChanged` dispatcher 13 requests `FHD_GetMixingTime` 36, `GT_Ticks` index 4, through the host dispatcher. The controlled callback writes a 16-byte `TFPTime` pair. Native instruction `5c110` truncates the first double to signed 64; `5c114` takes its low 32 bits. Helpers `1bc790`/`1bc6f0` and integer-multiply `4a78` relocate each registered phase by the increment times that low 32 tick, retaining low 32. The reconstructed helper accepts finite ticks in [−2^63,2^63), validates before mutation and uses defined unsigned modular arithmetic. Nonempty final frame `1bc640` clears pending; empty `GenRender` retains pending, dirty, refresh and registration.

The corpus uses 360 original factories, six tempos 60/90/120/137/240/1000 crossed with explicit PPQs 4/48/96/240/960/4096. Dispatcher 14 `FPD_SetTimeSig` receives PPQ at Value `+8`. Rate 44100, tempo and PPQ stay fixed within a fixture. Each fixture performs 256 randomized flag updates over 0..63, period controls 100..65536, volume-enabled changes, explicit ticks, seeks and alternating empty/nonempty eight-sample renders. Every operation compares registry count, order and mask, all five synchronized phases, dirty, refresh and pending. Nonzero guards surround the native eight-sample output region; this helper itself writes no audio. Prepared phase increments are separately checked against the native configuration.

Seek inputs include positive and negative fractions, signed 32 boundaries, wraparound at 2^32,2^52 and finite values near signed 64 limits. Invalid own-API times (NaN, infinities and out-of-range doubles) must leave all state bytes unchanged; those invalid calls are not sent to the original. The original host time request count must exactly equal the delivered seek count. The manifest records the final counts and exact source/artifact identities.

This evidence covers metadata under controlled host delivery. Actual application clock production, live context changes, synchronized reconstructed audio, release-refresh application, cross-channel interactions, native object/state/editor ABI, host project execution and complete Fruity/VST/AU equivalence remain open. The nonsynchronized channel/audio corpora exclude synchronized flag 32; this metadata module does not extend their audio claims.
