# Vial source-build matrix

This original host fixture measures the optional GPL **Vial 1.0.6** research
wrapper built by `../external/vial/build.sh`. It requires no installed Vital,
commercial preset or captured reference state. Installed **Vital 1.0.7** remains
a different version. The recipe's disclosed sample-state offset patch changes
reference behavior; this matrix does not establish version equivalence.

For a source-only run that builds into a new review-owned directory:

```sh
python3 reconstruction/plugins/review/verify_vial_matrix.py
```

To inspect existing recipe output without modifying it:

```sh
python3 reconstruction/plugins/review/verify_vial_matrix.py \
  --source-build-directory /absolute/path/to/recipe-output
```

The runner copies the generated bundle into its private output directory and
compiles an original host fixture with AddressSanitizer/UndefinedBehaviorSanitizer.
The upstream plugin library itself is not sanitizer-instrumented. Each case
uses a separate process with a 60-second limit, bounded sample buffers and
private state captures. Outputs stay under `.tools/plugin-work/review/` by
default. `--smoke` selects one 48 kHz/512-frame case; reports always state the
actual planned and completed counts. A report is not marked passed before all
planned cases complete.

The 56-case matrix is:

| Rates in Hz | Announced blocks in frames | Cases |
| --- | --- | --- |
| 8000, 44100, 48000, 96000, 192000 | 1, 2, 3, 31, 64, 511, 512, 1024, 8191, 8192 | 50 |
| 8001, 191999 | 1, 511, 8192 | 6 |

Every case checks source-version/factory metadata, generated valid-state
restore/save, zero and short actual-block guards, out-of-short-block MIDI
discard, finite nonzero note output, release/reprepare and destruction through
the host fixture's normal cleanup. The audio window is bounded to the larger
of one quarter second and two announced blocks. This finite matrix samples the
advertised range; it does not exhaust every rate/block combination or prove
realtime behavior, GUI or host automation.

Nine cases additionally repeat 20 valid-state restores: rates 8000/48000/192000
and blocks 1/511/8192. All other cases restore once. State is generated by the
new source-built factory and copied before restoration. Persistent JSON and
state envelope must match exactly, while adjacent and cumulative PCM16 changes
from the initial state must each stay within one unit. Exact byte equality is
recorded separately. A one-unit initial conversion followed by a fixed point
is described as tolerant stability followed by exact pairs, not exact
idempotence from the initial state.

Only generated valid upstream JSON chunks are supplied. Arbitrary/malformed
state rejection and the upstream modal-error path remain unverified. This is a
source-build processing/state matrix, not a full installed-plugin certificate.
